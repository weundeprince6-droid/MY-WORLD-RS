            Telegram

            Comment connecter mon bot Telegram (2 minutes)
            1. Sur Telegram, ouvrez la conversation avec @BotFather et envoyez /newbot.
            2. Choisissez un nom, puis un identifiant qui se termine par « bot » (exemple : MonRS_bot).
            3. BotFather vous donne un jeton (123456789:AAH…). Copiez-le et collez-le ci-dessous.
            4. Pour recevoir un message : ouvrez votre bot et écrivez-lui, ou transférez-lui un message reçu.
            5. Pour lire un groupe : ajoutez le bot au groupe, puis envoyez /setprivacy à @BotFather, choisissez votre bot et Disable.

            Le jeton reste uniquement dans ce navigateur. Telegram garde les messages non lus pendant 24 heures : ouvrez le tableau de bord au moins une fois par jour.

            Facebook (vos Pages)

            Comment connecter mes Pages Facebook (10 minutes)
            1. Sur developers.facebook.com, connectez-vous puis Mes applications > Créer une application. Vous en êtes automatiquement l'administrateur.
            2. Ajoutez à l'application le cas d'utilisation Messenger (pour obtenir la permission pages_messaging).
            3. Ouvrez Outils > Graph API Explorer et choisissez votre application.
            4. Ajoutez les autorisations pages_show_list, pages_read_engagement, pages_manage_metadata et pages_messaging, puis Generate Access Token en sélectionnant vos Pages.
            5. Ce jeton dure environ 1 heure. Collez-le dans Outils > Access Token Debugger, cliquez sur Extend Access Token et copiez le nouveau jeton (valable environ 60 jours).
            6. Collez-le ci-dessous.

            Seuls les messages reçus par vos Pages sont lus (jamais votre Messenger ou votre profil personnel). Vous devez administrer la Page. Le jeton reste uniquement dans ce navigateur.

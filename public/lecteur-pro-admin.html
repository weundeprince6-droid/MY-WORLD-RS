N'émettez le code qu'après avoir confirmé le paiement reçu. La référence est obligatoire pour l'audit.

Règles de sécurité

  • Connexion Google obligatoire.
  • Seul le compte administrateur autorisé peut émettre ou désactiver une licence.
  • Une licence est liée au compte e-mail de l'acheteur et à un seul compte utilisateur.
  • Le code complet n'est affiché qu'à sa création.
  • Les paiements ne sont pas encaissés par cette interface.
